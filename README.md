# AI 人生记录 · 交互原型

[在线体验](https://ByelikovTao.github.io/ai-life-record-prototype/) · [三屏总览](https://ByelikovTao.github.io/ai-life-record-prototype/overview.html)

这是用于设计评审的静态页面原型，包含人物档案、视频与照片、人生传记、数字人文字交互、家庭关系和三维记忆空间。业务人物、经历、支付与授权均为演示；不连接真实账号、支付或 AI 服务。

## 本地查看

下载完整仓库后，用 Chrome 或 Edge 打开 `index.html`，保留相邻 CSS、JavaScript、`assets` 和 `vendor` 文件。无需安装依赖。刷新页面会重置演示状态。

## 部署

推送到 `main` 或手动运行“发布原型到 GitHub Pages”工作流，即可更新在线版本。Pages 使用 GitHub 自动提供的部署凭据。

## 素材

素材来源与授权说明保留在 `assets` 和 `vendor` 内；第三方素材沿用各自许可。

## 故人分享新流程（2026-10-29）

[直接体验归家](https://ByelikovTao.github.io/ai-life-record-prototype/?embedded=1#home) · [独立访客示例](https://ByelikovTao.github.io/ai-life-record-prototype/memory.html)

首页往事后进入“与故人说旧事”，以档案本人演示身份选择照片或影片、寄语、预览确认后自主分享。访客无需安装或登录，可自愿打开预约表单。照片详情有独立修复示例，服务与订单中可查看双向记忆服务礼。

全部为虚构示例：修复使用预制效果，预约只在当前页面内存生成演示回执，不发送、不保存真实联系方式；服务礼为手动推进的演示状态。真实AI、预约后台、服务履约和可撤回短链尚未接入。分享链接携带本人确认的单份示例快照，可转发，仅限示例资料。

故里现仅保留“看看老家”全景，已移除屋子全貌和四处走走选项；年代、缩放、物件故事和全屏保留。

分享前核对已增加黑白修复上色、模拟年轻模样两种可选体验，支持原片对照、选用与恢复。效果为预制AI示例，尚未接入任意图片的实时生成；访客页保留AI模拟标记。
