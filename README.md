# 灯火传家 · 在线交互原型

[直接体验](https://ByelikovTao.github.io/ai-life-record-prototype/?embedded=1#home) · [三屏总览](https://ByelikovTao.github.io/ai-life-record-prototype/overview.html)

归家、往事、叙话、故里、我的家共用中式山水纸笺主题。人物、照片、视频、订单与服务均为虚构演示。

## 故人共忆

“与故人说旧事”与“故人共忆”已合并：归家底部只有一个入口。本人选已有照片或影片、可选AI效果和寄语，核对一次后生成同一份共忆链接。朋友无需登录，可只观看，也可自愿补充文字或照片；朋友先确认，档案主再决定是否收录。没有第二套邀请选材页。

支持同浏览器演示同步；跨设备可下载JSON回执交本人导入。新分享保留朋友署名，不改原档案。拍摄咨询与双向服务礼仍可从原入口体验。

## 演示边界

当前是静态原型，数据只保存在页面内存，刷新即清空。AI修复及年轻模拟使用预制效果，未接入实时AI。预约不会实际发送，服务礼不实际发放。没有真实账号认证、后台、跨设备自动同步或可撤回短链。邀请链接是确认后的快照、可转发；请只使用示例资料测试。

## 本地查看和部署

保留index.html相邻的CSS、JavaScript、assets和vendor文件，使用Chrome或Edge打开即可，无需安装依赖。推送main会触发现有GitHub Pages工作流，使用GitHub提供的部署凭据。

素材来源与许可说明保留在assets和vendor目录，第三方素材沿用各自许可。prototype-release.json记录当前源代码版本。
